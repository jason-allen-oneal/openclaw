# Native Android pairing recovery proof host contract

Driver `driver.mjs` will start an isolated BUILT candidate Gateway, a transparent WebSocket recording proxy, and an HTTP control server. No production server or physical phone is used. It writes `private-runtime/native-args.json` after readiness: `{host:"10.0.2.2",gatewayPort:<proxy-port>,controlPort:<http-port>,token:<synthetic-token>,candidateSha:<SHA>}`. All control POST bodies JSON, responses JSON `{ok:true,...}`; failures status500 `{ok:false,error}`. HTTP Authorization is `Bearer <synthetic-token>` (same isolated token). Native test must target dedicated fresh emulator/test package, never real retained user identity.

1. POST `/identity` with `{deviceId,publicKeyRawBase64,privateKeyPkcs8Base64}` from **production `DeviceIdentityStore.loadOrCreate()`**. Driver validates key consistency, pre-approves only this synthetic test identity through public pairing RPCs using matching client metadata (below), closes initial fixture. No manual pairing/retry occurs during the recovery scenario.
2. Native connects production GatewaySession with normal token and signed identity, role`node`, scopes/caps/commands empty, permissions empty. Client: id`openclaw-android`, displayName`Android pairing recovery native proof`, version`test`, platform`android`, mode`node`, instanceId`pairing-recovery-android`, deviceFamily`android`, modelIdentifier`test`.
3. Once native ready, POST `/ready` `{}`; asserts the registry connected. POST `/replace` `{}`; host authenticates same identity on another real socket, sends `node.host.stats` with cpuCount4,total8192,free4096; returns operator node.list readback.
4. Native sends obsolete node.host.stats free1024 through current production lease/session. Observe `ok:false/error.code=UNAVAILABLE/details.code=PAIRING_CHANGED`, close4001, old lease invalid, onDisconnected/readiness withdrawn. Immediately POST `/check-rejected` `{}`; driver asserts operator readback free4096 and obsolete request has no effect. Automatic reconnect uses normal production timing; no manual retry/network change.
5. Native waits automatically authenticated second readiness, sends a **NEW** stats event free6144. POST `/check-recovered` `{}`; asserts registry connected/free6144, proxy confirms exactly2 authenticated Android connects, stale1024 sent exactly once (not replayed), fresh6144 once, and rejection precedes close4001.
6. POST `/finish` `{passed:true,observations:{...}}` only after native assertions complete. On failure send `{passed:false,error:"..."}`. Driver emits sanitized manifest/summary/wiretrace/logs and shuts owned processes. Driver has bounded overall timeout and handles SIGTERM cleanup.

GatewaySession detailed event method may encode payload as `payloadJSON`; host normalizes both direct`payload` and`payloadJSON` for assertions. Bind actual APK/testAPK hashes separately in parent proof manifest. The proxy forwards real frames unmodified; it neither fabricates RPCs nor initiates recovery. Host control records lifecycle observations but Android JUnit output is the authoritative assertion result. Emulator/native transport proof, not physical phone or full UI proof.
